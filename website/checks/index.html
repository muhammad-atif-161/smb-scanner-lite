Capabilities

Twenty-two controls, told as five groups.

The full catalog covers DNS integrity, email authentication, transport, browser headers and service exposure. A report never hides a skipped check: if something was not tested, it says so. The public sandbox runs the read-only subset that applies to each target.

The catalog

Expand any group to see the individual checks.

Each check is read-only. The network exposure group sends a single protocol-level probe that identifies a service — it does not authenticate, list shares, or exploit anything.

DNS & domain security

Whether the name resolves, whether the zone is signed, and whether a stranger can copy or redirect it.

  • Address resolution and record presence
  • DNSSEC chain validation
  • CAA — which certificate authorities may issue for the domain
  • Zone transfer attempts against the secondary
  • Stale or reused name records pointing at retired infrastructure
Email authentication

Whether a stranger can send mail that looks like it came from the domain.

  • SPF — does it actually fail unauthorised senders
  • DMARC policy, and whether it enforces or only monitors
  • DKIM key length and presence
  • MX records, including a domain that has chosen to receive no mail
  • Consistency between the sending and authentication identities
Network & service exposure

Which high-risk services answer from the public internet, and whether they ask for a signature.

  • Protocol-checked reachability of high-risk ports
  • SMB on 445 through a single unauthenticated negotiate
  • Remote desktop reachability
  • Database and management interfaces that should not be public
  • No login attempt, no share listing, no payload
Transport & browser headers

How carefully the site treats the browsers that visit it.

  • TLS versions offered and certificate validity
  • HTTP to HTTPS redirect
  • HSTS, Content-Security-Policy, clickjacking and sniffing protection
  • Cookie, CORS and referrer policy
  • Server banner and version disclosure
Assessment summary

One score, explained rather than asserted.

  • Posture score and letter grade
  • Severity assigned to each finding
  • The evidence string behind every conclusive result
  • Inconclusive results reported separately from failures
  • Consent receipt embedded in every report

The public sandbox demonstrates the same standard. The published edition runs the same reporting and scoring path against five free testing domains. It does not publish the full engine, the complete catalog, or the internal test suite.

A capability listed here is implemented in the current public version. Nothing is advertised that the published code does not do.
