Documentation

Install the sandbox. It will not scan the open internet.

The published copy is the sandbox edition. Before any lookup it checks the name against five domains and requires a signed consent.

Try the web demoView source

1 · Clone and install

python 3.10+
git clone https://github.com/muhammad-atif-161/smb-scanner-lite.git
cd smb-scanner-lite
pip install -e .

2 · List the permitted targets

read-only

The command prints the five approved domains and nothing else. It makes no network request.

smb-scanner --list-domains

3 · Run an assessment

consent required

Consent is mandatory. Without --accept-privacy-policy and a name, the tool will prompt interactively and refuse if you do not agree.

smb-scanner example.com \
  --accept-privacy-policy \
  --consent-user "Your Name" \
  --html report.html

4 · Verify the consent ledger

sha256 chain

Every receipt is chained to the previous one. Verification tells you whether the ledger on this machine is intact.

smb-scanner --verify-consent-log

The only five names

The allowlist is the product boundary.

Any other name — including a look-alike subdomain, a raw IP address, or a trailing dot — is rejected before a network request is made.

  • example.comIANA reserved standard test domain
  • example.orgIANA reserved organization test domain
  • example.netIANA reserved network test domain
  • scanme.nmap.orgNmap project authorised test host
  • badssl.comPublic TLS & certificate teaching site

This restriction lives in the runtime, not in the interface. The sandbox edition cannot be pointed at an arbitrary host by editing a setting or a flag.

What you get back

A short report, in the format you asked for.

A posture score, the evidence string for each conclusive check, the controls that returned no answer, and the consent receipt that proves you agreed first. Write it as HTML, JSON or text.

  • Score, grade and completed-control count
  • One evidence line per conclusive finding
  • Inconclusive results listed separately
  • Embedded consent receipt, hash-chained
  • Nothing is uploaded to this website
