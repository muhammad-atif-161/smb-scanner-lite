How it works

Install the sandbox. It will not scan the open internet.

The copy in this public repository is the sandbox edition. Before any lookup it checks the name against five domains and requires a signed consent.

git clone https://github.com/muhammad-atif-161/smb-scanner-lite.git
cd smb-scanner-lite
pip install -e .
smb-scanner --list-domains
smb-scanner example.com --accept-privacy-policy --consent-user "Your Name" --html report.html

The only five names

  • example.com — reserved example domain
  • example.org — reserved example domain
  • example.net — reserved example domain
  • scanme.nmap.org — Nmap’s public test host
  • badssl.com — public TLS teaching site

Any other name, including a look-alike subdomain or a raw IP address, is rejected before a network request is made.

What you get back

A short report: a posture score, the evidence string for each conclusive check, and the consent receipt id that proves you agreed first. HTML, JSON, or text. Nothing is uploaded to this website.
