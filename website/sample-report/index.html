Executive summary

example.com demonstrates strong DNSSEC, SPF (-all) and DMARC enforcement, with informational web security header gaps typical of a minimal RFC reference site.

DNS & Domain Hygiene95
E-mail Authentication92
Transport Security (TLS)90
Web Security Headers68

What this result means

Eight controls completed and none returned an inconclusive answer, so the score covers every check that ran. DNS, email authentication and transport are strong. The two warnings are informational browser-header gaps typical of a minimal reference site.

What it does not mean

A grade B is not a statement that the domain is secure. It means the controls that were measured met their expectations, subject to the limitations of external observation. No application, identity system or internal network was examined.

Scope

External and read-only. The assessment queried public DNS records, completed TLS handshakes, read HTTP response headers, and made no authentication attempt of any kind.

Why a consent receipt is in a report

Before any run, the operator accepts the privacy policy and signs a receipt that is hash-chained to the previous one. The receipt is embedded in the report so the authorisation behind the result travels with it. It is stored on the machine that ran the assessment, not on this website.
