SMB Scanner Lite

Public Sandbox Edition · 5-domain locked · Mandatory consent

Educational external security posture demo

This public repository hosts only the sandbox-safe face of the project. The full scanning engine stays private. You can only assess these five free-to-use testing domains:

  • example.com
  • example.org
  • example.net
  • scanme.nmap.org
  • badssl.com

Run the sandbox tool

git clone https://github.com/muhammad-atif-161/smb-scanner-lite.git
cd smb-scanner-lite
pip install -e .
smb-scanner --list-domains
smb-scanner example.com --accept-privacy-policy --consent-user "Your Name"

Read the Privacy Policy before scanning. Every run produces a cryptographic consent proof.
