Ethical guarantee

A scanner that is proud of what it refuses to do.

  • Authorised use only. The full engine is for domains you own or have written permission to assess. This website does not distribute that unrestricted engine.
  • Public lock. The published program allows five testing domains and nothing else.
  • No claim without evidence. A finding quotes what was observed: the record, the header, the handshake. Silence from the network is inconclusive, not an invented failure.
  • No exploitation. SMB is identified with a single unauthenticated negotiate. There is no login, no share listing, and no payload.
  • Consent before action. Each sandbox run stores a hash-chained receipt on the operator’s own machine. It is not sent here.
  • Not a commercial audit. A sandbox report is a lesson and a demonstration. It is not a certificate that a business is “secure.”

Read the privacy policy before you run anything.
