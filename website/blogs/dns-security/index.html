DNS and domain security

DNS is the part of your infrastructure everyone depends on and almost nobody reads. It is also completely observable from outside, which makes it the cheapest place to find real problems.

1 post Updated 31 October 2026 Cluster guide

Every customer who types your domain name is trusting an answer they did not verify. DNS is the system that answers them: where the website lives, where mail goes, which certificate authority may issue for the name, and increasingly whether the answer itself was signed.

Because those answers are public by design, an outsider can audit them without touching anything private. That is the unusual advantage of DNS security work: nearly all of it is inspection, and almost none of it requires access.

Every post in this cluster ends with the same question: what would you do on Monday? Where a check can be run by hand, the command is in the post. Where it cannot, the post says so rather than implying a tool will handle it.
