What "recorded" means here

An SMB Scanner Lite run was executed against a reserved test domain with the operator's consent. Its output was stored as static data. This page replays that output. It does not contact example.com, it does not scan your domain, and it cannot be made to scan anything else.

  • The score, grade, findings and evidence are the recorded values
  • The timestamp is the moment the assessment ran
  • Profiles without a dated capture are labelled as reference profiles
  • Nothing is generated to look plausible

Why the demo is restricted

A public scanner that can be aimed at anyone is a weapon.

The allowlist is enforced inside the runtime, not in this interface. A look-alike subdomain, a raw IP address, a trailing dot or a different port is rejected before a network request is made.

  • Five names, nothing elseexample.com, example.org, example.net, scanme.nmap.org, badssl.com
  • Rejection happens firstValidation precedes any lookup, so an unapproved target never generates traffic.
  • No arbitrary inputThis page offers buttons, not a text field. Even the buttons are checked against the allowlist again before data is displayed.
  • Consent before actionThe actual command-line sandbox requires an accepted policy and a signed receipt before it runs.
