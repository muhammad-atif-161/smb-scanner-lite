Before you submit

What this demo is, and what it is not.

This website is a static publication. It does not run scans and it has no backend. The panel on the left renders the assessment workflow and a clearly labelled demonstration report, so you can see what the output looks like before you install anything.

  • Permitted targets are the whole list.The five domains below, and nothing else. A look-alike subdomain or a raw IP address is rejected.
  • Consent comes first.A scan never starts until the operator accepts the policy and signs a receipt.
  • Read-only by design.DNS queries, mail policy lookups, TLS handshakes, response headers and one protocol-level probe. No login, no exploit.
  • The real run happens on your machine.Install the sandbox from the documentation page to perform an actual assessment.

The website never claims more than the backend enforces. On this static site the allowlist is enforced in the published sandbox runtime, not in a browser. If a form here accepts something the runtime would reject, the form is wrong — report it.

Permitted targets

Five domains. That is the entire public surface.

Every one of these is free to use, publicly documented, and explicitly designated for testing. They exist so the tool can be demonstrated without touching anyone’s infrastructure.

example.com

IANA reserved standard test domain

example.org

IANA reserved organization test domain

example.net

IANA reserved network test domain

scanme.nmap.org

Nmap project authorised test host

badssl.com

Public TLS & certificate teaching site

Any other target is rejected before a network request is made. This restriction is enforced by the sandbox runtime and cannot be changed from the command line, the GUI, or a configuration file.

Error states

Every refusal explains itself.

A rejection should tell the operator what happened and what to do next. These are the states the interface is designed to handle.

Invalid domain input

The value is empty, contains spaces, or is not a syntactically valid domain name. The field keeps your input and names the problem.

Target not on the allowlist

The domain is not one of the five approved test targets. No network request is made, and the message lists the permitted domains.

Unsupported target

An IP address, a CIDR range, a port, or a URL was supplied. This edition works with domain names only.

Rate limit reached

Too many assessments were requested in a short window. Wait a minute and try again — no partial result is produced.

Assessment still running

The run has started and has not finished. The interface shows progress rather than inventing a result.

Assessment failed

A step could not complete at all. The error says which step, and no score is produced from a partial run.

No findings available

Every control came back inconclusive, so there is nothing conclusive to report. The report says so rather than printing a blank score.

Network or server error

The request did not reach the tool. Nothing was scanned, and nothing was recorded.
