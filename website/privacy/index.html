Privacy policy

Your report is not public content.

This policy describes the current website, the prepared Cloudflare backend and the separate desktop sandbox. Last reviewed 4 November 2026.

Who operates the service

SMB Scanner Lite is independently developed by Muhammad Atif. For privacy questions, write to myself.atiff@gmail.com.

Public website

The website is served as static pages through GitHub Pages. It does not include advertising pixels, third-party analytics SDKs or tracking cookies. Hosting and network providers may process ordinary request information such as IP addresses and access logs for operations, security and abuse prevention.

Online assessment data

Once enabled, the Cloudflare Worker collects the name and email submitted with a request, the target public domain, DNS-verification state, timestamps, operational job status and private assessment results. Cloudflare D1 stores assessment records and reports. A hashed access token authorizes report preview and status; the token is given to the customer once. IP addresses may be converted to keyed hashes for basic abuse limiting.

How results are accessed

The browser stores a private recovery token in session storage for the active tab. Only a holder of that token can request the preview or report. Results are not published on the website. Do not share the token; anyone who has it may be able to access the assessment.

Payment processing

Checkout is not active in the current private beta. No payment is collected. Before paid profiles launch, the page will state the price and what is included before any checkout begins.

Enquiries

The manual form uses your mail application unless a dedicated contact endpoint is configured. A composed email is only delivered after you send it. Avoid including passwords or sensitive business records in an enquiry.

Desktop sandbox

The downloadable public Python sandbox runs on your own device. Its local consent receipts and output files are not automatically uploaded to the SaaS backend. The desktop runtime has a separate five-domain testing restriction.

Retention, access and deletion

Reports are stored privately to serve assessment status and results. Operational report retention and deletion rules must be finalized before public online assessment onboarding. No indefinite retention promise or automatic purge is claimed here. Contact us about access or deletion of assessment records; requests are reviewed against available records and applicable obligations.

Changes

The service is in an early release stage. Material changes to collection, payment processing or report access should be reflected in a revised privacy notice before activation.
