Privacy

Privacy policy & consent agreement

Effective 24 October 2026 · Policy version 2026.10-sandbox-v1 · Maintainer Muhammad Atif.

Try the demo Authorised use

1 · Purpose and public sandbox restriction

SMB Scanner Lite (Public Sandbox Edition) is an educational defensive security posture demonstration tool created to illustrate external DNS, email authentication, TLS and HTTP header hygiene concepts safely and responsibly.

To prevent misuse or unauthorised scanning of third-party infrastructure:

  • The full internal source code of the scanner is kept private and is not distributed in the public repository.
  • All public executions — CLI, GUI and web portal — are hard-locked to five publicly free-to-use testing domains.
  • Any attempt to scan a domain, hostname or IP address outside those five is rejected before any network request is made.

2 · Mandatory pre-scan user consent

Before any scan is initiated — command line, graphical interface or website — the user must explicitly review and accept this policy. Granting consent generates a tamper-evident consent proof receipt containing:

  • consent_id — unique receipt identifier
  • timestamp_utc — exact ISO-8601 UTC timestamp
  • operator — the name or handle that gave consent
  • target — the approved public sandbox domain
  • policy_version and policy_sha256 — digest of the accepted policy
  • prev_receipt_hash and receipt_sha256 — SHA-256 hash chain

Every scan report embeds the corresponding consent receipt as verifiable proof that consent was obtained prior to execution.

3 · Data handling

SMB Scanner Lite does not sell, rent, or transmit personal information to any advertising or analytics network.

When you run the CLI or GUI on your own computer, consent receipts are written locally — by default under your home directory — and are excluded from public Git commits. During an approved sandbox run the tool performs standard read-only DNS and HTTPS header lookups strictly against the selected domain from the five approved public test targets.

4 · Acceptable use

By using SMB Scanner Lite you agree not to:

  • attempt to bypass, modify or circumvent the five-domain public sandbox allowlist;
  • reverse-engineer, decompile or extract the protected runtime package;
  • misrepresent educational sandbox reports as formal commercial security audits; or
  • use this software in violation of any applicable law.

5 · Disclaimer of warranty

SMB Scanner Lite is provided “AS IS” for educational and defensive learning purposes only, without warranty of any kind. The author assumes no liability for misuse of the software.
