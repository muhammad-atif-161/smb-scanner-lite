Verified domain assessment / Online service

Start with proof of domain control.

The online service checks a defined set of public DNS and email controls. Ownership verification is required before any assessment can run. The result is an evidence report for this profile, not a complete security review.

Current release: private beta. Basic is planned as a free, limited DNS and email assessment. Standard and In-Depth are not yet available for self-service; pricing and availability will be stated before release.
